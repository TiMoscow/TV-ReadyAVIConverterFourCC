# Изменение описания видеокодека DivX (XviD) для совместимости с современными телевизорами

Этот проект позволяет автоматически изменять FourCC-код в AVI-файлах, чтобы видео в формате DivX (XviD) могли корректно воспроизводиться на современных телевизорах.

---

## 📋 Описание

Скрипт изменяет FourCC-код в AVI-файлах на `FMP4`, что обеспечивает совместимость с большинством современных устройств. Он автоматически обрабатывает все AVI-файлы в текущей директории и всех вложенных папках.

---

## 🛠️ Требования

- Установленный **[FFmpeg](https://ffmpeg.org/download.html)** (обязательно). Скачать можно [здесь](https://ffmpeg.org/download.html).
- Операционная система **Windows** (для работы с `.bat`-файлом).

---

## ⚙️ Установка FFmpeg и добавление в PATH

Для работы скрипта необходимо установить FFmpeg и добавить его в системную переменную PATH. Вот как это сделать:

1. **Скачайте FFmpeg**:
    - Перейдите на [официальный сайт FFmpeg](https://ffmpeg.org/download.html).
    - Скачайте версию для вашей операционной системы (например, Windows).

2. **Распакуйте архив**:
    - Распакуйте скачанный архив в удобное место, например, в `C:\FFmpeg`.

3. **Добавьте FFmpeg в PATH**:
    - Нажмите `Win + R`, введите `sysdm.cpl` и нажмите Enter.
    - Перейдите на вкладку **Дополнительно** и нажмите **Переменные среды**.
    - В разделе **Системные переменные** найдите переменную `Path` и выберите **Изменить**.
    - Нажмите **Создать** и добавьте путь к папке `bin` внутри распакованной папки FFmpeg (например, `C:\FFmpeg\bin`).
    - Нажмите **ОК** во всех окнах, чтобы сохранить изменения.

4. **Проверка установки**:
    - Откройте командную строку (`Win + R`, введите `cmd` и нажмите Enter).
    - Введите команду `ffmpeg -version`.
    - Если FFmpeg установлен правильно, вы увидите информацию о версии.

## 🚀 Использование

1. Поместите файл `process_videos.bat` в директорию с видеофайлами.
2. Запустите `process_videos.bat`.
3. Скрипт автоматически обработает все AVI-файлы в текущей директории и всех вложенных папках.

---

## 📂 Что делает скрипт

- Рекурсивно ищет все AVI-файлы в текущей директории.
- Изменяет FourCC-код на `FMP4` с помощью FFmpeg.
- Сохраняет изменения в исходных файлах.

---

## ❓ Почему это нужно?

Некоторые современные телевизоры и устройства не поддерживают старые FourCC-коды, такие как XviD или DivX. Изменение кода на `FMP4` позволяет избежать проблем с воспроизведением.
