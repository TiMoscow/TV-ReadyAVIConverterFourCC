# Изменение описания видеокодека DivX (XviD) для совместимости с современными телевизорами

Этот проект позволяет автоматически изменять FourCC-код в AVI-файлах, чтобы видео в формате DivX (XviD) могли корректно воспроизводиться на современных телевизорах.

---

## 📋 Описание

Скрипт изменяет FourCC-код в AVI-файлах на `FMP4`, что обеспечивает совместимость с большинством современных устройств. Он автоматически обрабатывает все AVI-файлы в текущей директории и всех вложенных папках.

---

## 🛠️ Требования

- Установленный **[Python 3.8+](https://www.python.org/downloads/)** (обязательно для `Способа 1`). Минимальная версия — **3.8**. Скачать можно [здесь](https://www.python.org/downloads/).
- Установленный **[FFmpeg](https://ffmpeg.org/download.html)** (обязательно). Подходит **любой стабильный билд** (например, 2.8+, 4.x, 5.x, 6.x, 7.x) — используется только базовый функционал. Скачать можно [здесь](https://ffmpeg.org/download.html).
- Операционная система **Windows** (для работы с `.bat`-файлом).

## ⚙️ Установка и добавление в PATH

Для работы скрипта `process_videos_start.bat` (Способ 1) необходимы **Python** и **FFmpeg**, причём оба должны быть доступны из командной строки (то есть добавлены в переменную PATH).
Для `process_videos_remux.bat` (Способ 2) нужен только **FFmpeg**.

### Установка Python

1. **Скачайте Python**:
    - Перейдите на [официальный сайт Python](https://www.python.org/downloads/).
    - Скачайте установщик для Windows.

2. **Установите**:
    - Запустите установщик и **обязательно отметьте галочку** «Add python.exe to PATH» (Добавить python.exe в PATH) внизу первого экрана, прежде чем нажать «Install Now».

3. **Проверка установки**:
    - Откройте командную строку (`Win + R`, введите `cmd` и нажмите Enter).
    - Введите команду `python --version`.
    - Если Python установлен правильно, вы увидите что-то вроде `Python 3.x.x`.

### Добавление Python в PATH вручную

Если при установке вы **не отметили** галочку «Add python.exe to PATH» или настройка сбилась — добавьте Python в PATH вручную:

1. **Найдите путь к Python**:
    - Откройте командную строку и выполните (работает даже если Python не в PATH):
      ```bat
      py -c "import sys,os;print(os.path.dirname(sys.executable))"
      ```
    - Вывод покажет папку установки (например, `C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\AppData\Local\Programs\Python\Python310`) — запомните её.

    - Если команда `py` не работает — найдите установку вручную. По умолчанию Python ставится сюда:
      `C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\AppData\Local\Programs\Python\Python310\`

2. **Откройте переменные среды**:
    - Нажмите `Win + R`, введите `sysdm.cpl` и нажмите Enter.
    - Перейдите на вкладку **Дополнительно** и нажмите **Переменные среды**.

3. **Добавьте пути**:
    - В разделе **Пользовательские переменные** (или **Системные переменные**) найдите переменную `Path` и выберите **Изменить**.
    - Нажмите **Создать** и добавьте путь к папке Python (например, `C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\AppData\Local\Programs\Python\Python310`).
    - Нажмите **Создать** ещё раз и добавьте путь к папке `Scripts` (например, `C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\AppData\Local\Programs\Python\Python310\Scripts`). Этот путь нужен для pip.
    - Нажмите **ОК** во всех окнах, чтобы сохранить изменения.

4. **Проверьте**:
    - **Откройте новую** командную строку (не старую — старые окна не видят изменения PATH) и введите:
      ```bat
      python --version
      pip --version
      ```
    - Если обе команды показывают версии — всё работает.

> **Важно про путь:** `ИМЯ_ПОЛЬЗОВАТЕЛЯ` в примерах — это ваша реальная учётная запись Windows, у каждого она своя (например, `ivan`, `petr`, ...). Не копируйте примеры слепо — подставляйте тот путь, который выдала команда `py` в шаге 1.

### Установка FFmpeg и добавление в PATH

Для работы скрипта необходимо установить FFmpeg и добавить его в системную переменную PATH. Вот как это сделать:

1. **Скачайте FFmpeg**:
    - Перейдите на [официальный сайт FFmpeg](https://ffmpeg.org/download.html).
    - Скачайте версию для вашей операционной системы (например, Windows).

2. **Распакуйте архив**:
    - Распакуйте скачанный архив в удобное место, например, в `C:\FFmpeg`.

3. **Добавьте FFmpeg в PATH**:
    - Нажмите `Win + R`, введите `sysdm.cpl` и нажмите Enter.
    - Перейдите на вкладку **Дополнительно** и нажмите **Переменные среды**.
    - В разделе **Системные переменные** найдите переменную `Path` и выберите **Изменить**.
    - Нажмите **Создать** и добавьте путь к папке `bin` внутри распакованной папки FFmpeg (например, `C:\FFmpeg\bin`).
    - Нажмите **ОК** во всех окнах, чтобы сохранить изменения.

4. **Проверка установки**:
    - Откройте командную строку (`Win + R`, введите `cmd` и нажмите Enter).
    - Введите команду `ffmpeg -version`.
    - Если FFmpeg установлен правильно, вы увидите информацию о версии.

> **Важно:** если `python` или `ffmpeg` не найдены (`'python' is not recognized...` или `'ffmpeg' is not recognized...`), значит нужный путь не в переменной PATH — повторите шаги установки или проверьте переменные среды.

## Способ 1: точечная замена FourCC 🚀 (рекомендуется)
1. Поместите файлы `process_videos_start.bat` и `process_videos.py`  в директорию с видеофайлами.
2. Запустите `process_videos_start.bat`.
3. Скрипт автоматически обработает все .avi файлы в текущей директории и всех вложенных папках.
4. Для каждого изменённого видео будет проведена проверка на целостность, после чего будет сохранен новый файл
5. Все результаты работы скрипта сохраняются в лог-файл fourcc_change_log.txt рядом с скриптом.


## Способ 2: пересборка AVI-контейнера (remux)
Используется метод пересборки контейнера с сохранением потоков (без перекодирования).

1. Поместите файл process_videos_remux.bat в директорию с видеофайлами.
2. Запустите process_videos_remux.bat.
3. Скрипт обработает все .avi файлы в текущей директории и во всех вложенных папках.

 **📌 Используется в случаях, когда:** 
- AVI имеет нестандартную структуру
- точечная замена FourCC не даёт результата

---

## 📂 Что делает скрипт

- Рекурсивно ищет все AVI-файлы в текущей директории.
- Изменяет FourCC-код на `FMP4` с помощью FFmpeg.
- Сохраняет изменения в исходных файлах.

---

## ❓ Почему это нужно?

Некоторые современные телевизоры и устройства не поддерживают старые FourCC-коды, такие как XviD или DivX. Изменение кода на `FMP4` позволяет избежать проблем с воспроизведением.
